# Intelligent Timetable & Room Allocation System

A constraint-based scheduling application designed to generate valid college timetables and suggest optimized alternatives based on academic and resource requirements.

## Features

- **Automated Timetable Generation:** Generate multiple valid timetables based on subjects, teachers, sections, and classroom availability.
- **Conflict Prevention:** Prevent teacher, classroom, and section scheduling conflicts.
- **Constraint Validation:** Account for room capacity, laboratory requirements, and weekly subject requirements.
- **Schedule Optimization:** Prioritize fewer scheduling gaps, balanced workloads, and efficient room utilization.
- **Admin Dashboard:** Compare timetable alternatives, select a preferred schedule, and publish the final allocation.

## Tech Stack

- Frontend: React
- Backend: Node.js
- Database: PostgreSQL
- Scheduling Algorithm: Constraint-based scheduling with heuristic optimization
